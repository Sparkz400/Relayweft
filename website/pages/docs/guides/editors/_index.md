Two editor plugins run on the same engine as `rw web` (`rw web --client`): the agent tree, the activity log, plan approval, follow-ups, undo, and change review in the editor's own diff view with per-hunk accept and reject.

- [VS Code](vscode.md)
- [JetBrains IDEs](jetbrains.md) (IntelliJ IDEA, PyCharm, GoLand, WebStorm, Rider and the others, 2025.2 or newer)

Neither is in a marketplace yet: you build and install them from the repository.
