# Package signing keys

These public keys verify Relayweft's Linux packages and apt, dnf and apk
repositories from v0.4.0. The private keys are GitHub repository secrets.

GPG fingerprint (`relayweft-signing-key.asc`):

```text
DEB4 253F B684 009B 87FC 2B6F A331 71A7 B774 1B8E
```

`relayweft-apk.rsa.pub` is the RSA public key for Alpine packages and indexes.
See [installation and verification](../README.md#apt-dnf-and-apk-repositories).
