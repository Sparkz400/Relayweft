## Relayweft v0.4.0

This release adds Bitbucket Cloud and Azure DevOps, conflict resolution,
`rw mcp`, shell completion, a documentation site, and signed Linux packages.
It also fixes process cleanup, affected test selection, concurrent git
operations and resume tracking. See the [full changelog](https://github.com/Sparkz400/Relayweft/blob/v0.4.0/CHANGELOG.md).

### Upgrade

- **Downloaded v0.3.0 binary:** run `rw update`, then `rw version`.
- **Package manager:** update through Scoop, Homebrew, apt, dnf or apk.
  The repository's Scoop, Homebrew and AUR manifests are updated after
  publication. See [installation](https://sparkz400.github.io/Relayweft/docs/start/install/).
- **Switchyard v0.1.0 or v0.2.0 (`sy`):** reinstall once as `rw` and follow
  the [rename guide](https://github.com/Sparkz400/Relayweft/blob/v0.4.0/packaging/release-notes/v0.3.0.md).

### New workflows

- **Bitbucket Cloud and Azure DevOps:** create pull requests, take issues
  or work items as tasks, and follow review comments and failed checks.
  [Bitbucket setup](https://github.com/Sparkz400/Relayweft/blob/v0.4.0/docs/bitbucket.md)
  and [Azure DevOps setup](https://github.com/Sparkz400/Relayweft/blob/v0.4.0/docs/azure-devops.md)
  describe tokens and API differences. Both integrations have automated
  API tests; live organization validation remains open.
- **Conflict resolution:** agents can reconcile overlapping work in a
  pool worktree. Your own uncommitted edits require approval by default;
  checks run before the result lands. See [conflict modes](https://github.com/Sparkz400/Relayweft/blob/v0.4.0/docs/conflicts.md).
- **`rw mcp`:** delegate tasks from Claude Code or Codex and follow their
  plans, changes and results. Its conflict approval path preserves the
  work on a branch when approval cannot be requested. See [MCP setup](https://github.com/Sparkz400/Relayweft/blob/v0.4.0/docs/mcp.md).
- **Completion and docs:** `rw completion bash|zsh|fish|powershell`, a
  generated config reference, and [searchable documentation](https://sparkz400.github.io/Relayweft/).

### Release verification

All six platform binaries have CycloneDX SBOMs and GitHub attestations.
`checksums.txt` has a keyless Sigstore signature. The Linux packages and
apt, dnf and apk repository metadata are signed with the project's package
keys, which are included in the release and committed in `packaging/keys/`.

Follow [Verifying a release](https://github.com/Sparkz400/Relayweft/blob/v0.4.0/packaging/README.md#verifying-a-release).
`rw update` checks SHA-256 and prints an attestation verification command;
it does not itself verify Sigstore signatures. Windows Authenticode and
Apple notarization are not part of this release.
